# Planning Prompt (Reference)

Working title & theme

    Title of the CTF challenge (e.g., The Encrypted Tunnel)
    Brief statement of the theme (e.g., “focuses on Wireshark packet capture and detecting ARP spoofing”)

Problem statement: 

    What cybersecurity concept(s) or networking topics does the challenge aim to teach/test
    Why is this concept relevant to the CTF scavenger hunt theme

Intended Challenge Type

    Format (e.g., multiple-choice, forensic log analysis, cryptography puzzle, packet capture, exploiting a misconfiguration).
    Difficulty level (beginner/intermediate / advanced).

Preliminary Challenge Outline

    A short description of what the user (the solver) will be asked to do.
    Tools or knowledge areas required (e.g., Wireshark, Nmap, Linux CLI). 

Flag concept

    Proposed flag format (static or dynamic).
    Description of how the flag would be obtained.

Resource / Deliverable list

    What resources would you need to prepare  (logs, pcap, encoded messages, config files, etc.).

Timeline plan

    Short list of tasks with estimated time allocations.
